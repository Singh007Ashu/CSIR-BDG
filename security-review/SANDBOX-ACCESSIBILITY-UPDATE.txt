SCOPE / OPEN ITEMS — NOT A PRODUCTION CERTIFICATE
Automated accessibility scans do not certify WCAG conformance. Manual screen-reader,
keyboard/zoom assessment across all modal/error states remains required.
This isolates document parsing, not the entire web service or Windows host.
Docker daemon access is privileged; production should use a dedicated parser
service/host and reviewed service identities (see deployment/parser-sandbox).
Inline-style CSP migration, comprehensive contextual injection/penetration testing,
high-load/DoS assessment, legacy parser coverage and independent security review
are not claimed complete. Old uploaded files have not all been rescanned.
CSIR MySQL migration/restore, reverse-proxy/TLS, monitoring, backup operations,
identity/reset delivery policy and final business approval need IT participation.
The temporary Cloudflare URL depends on this desktop, Docker and tunnel remaining
running. This is controlled testing, not permanent CSIR hosting.
